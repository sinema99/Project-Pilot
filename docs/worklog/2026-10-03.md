# 2026-10-03

## Pixel world (crisp pixel filter) — built

Spec: [specs/pixel-world.md](../specs/pixel-world.md), grilled and built the same day. The old PIXEL
FILTER shrank the finished 1440p frame by reading one pixel per block, so outlines broke up and the
image shimmered. Its finest preset was 640x360, and `O` turned it on at 160x90. It is replaced by a
real low-res render. `PixelWorld` (a drop-in CanvasLayer in `trial.tscn`) renders the 3D world in a
SubViewport that shares the main World3D, with a camera that copies the current camera every frame.
The root window stops drawing 3D, and a full-screen shader draws each texel as exactly N x N window
pixels. The UI stays sharp, and so does the hologram menu panel: it sits on render layer 20, which a
second full-res SubViewport draws on top only while the menu is open.

PIXEL FILTER is now OFF / 2X / 3X / 4X, on at 3X by default, stored under a new `pixel_size` key so
old saves boot into it. New COLOUR DEPTH row: FULL / 32 / 16 / 8, world only, works with pixels OFF
too. While pixelated, outlines and crease ink are 1 block, the rim light keeps its screen width,
MSAA is off, and RENDER SCALE / ANTI-ALIASING are greyed with "PIXEL FILTER ON". QA keys: `O`, `[`,
`]`, `\`.
