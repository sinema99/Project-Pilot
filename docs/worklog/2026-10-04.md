# 2026-10-04

## Painted shading — built

Spec: [specs/painted-shading.md](../specs/painted-shading.md), grilled (8 decisions) and built the
same day. The user liked the two-tone cel look but found the flat areas too flat, and wanted each
tone broken up with colours close to the original, Arcane-style, with no texturing.

Built inside the cel shader, not as a screen filter (screen noise slides over moving surfaces). The
base colour gets stepped, low-contrast patches before lighting, so light and shadow stay two tones
and both get mottled. Lighter patches lean warm and darker patches lean cool. Characters anchor the
pattern to UVs, so it rides the animated limbs. Level geometry (`cel_ground`) uses world-space
triplanar at about 1 m. `apply_stylized.gd` gives every styled mesh a stable `paint_seed` so
identical unwraps don't wear identical patches. New PAINTED SHADING settings row (graphics),
default ON, drives the `paint_strength` global. The metre grid and blockout boxes are untouched on
purpose.

Tuned from windowed probe shots: `paint_value` 0.06 (the proposed 0.04 barely showed), warmth 0.03,
`paint_uv_size` 0.1 (0.25 left each pilot9 limb on a single flat level). Subtle at shipped
strength, and it survives the 3X pixel filter.

New: `shaders/cel/includes/painted.gdshaderinc`, `tests/test_painted_shading.gd`,
`tests/_probe_paint_shot.gd`, `docs/specs/painted-shading.md`.
Edited: `cel-shader-base.gdshader`, `cel_ground.tres`, `project.godot` (7 `paint_*` globals),
`settings.gd`, `tab_settings.gd`, `apply_stylized.gd`, `docs/specs/settings.md`.

which this work did not touch. Not checkable headless: how it looks in motion. pilot9's limbs show
patches stretched along their length because of his Blender unwrap.

## Painted shading v2: map scale + angular shape

The user liked the patches but said they looked wrong on big map surfaces (1 m patches tiled across
20 m platforms) and wanted sharper shapes. Grilled 6 decisions, then built (spec section "v2"). The map now
uses two world layers (5 m + 1.25 m at 0.35, summed before stepping, still 3 tones). The patch shape,
on characters and map, is a Voronoi-polygon / cloud mix (`paint_angularity` 0.6). Spreads are
normalised so the tone split stays about a third each, verified by a Python sim of the shader noise.
Triplanar skips zero-weight planes to pay for the Voronoi.

Edited: `painted.gdshaderinc`, `cel-shader-base.gdshader`, `project.godot`,
`tests/test_painted_shading.gd`, `docs/specs/painted-shading.md`.

Suite: 919 tests, 1 failure, the same pre-existing `habitat: no generated child has an owner`.
Windowed probe shots look right at 5× strength. Not yet played.
