## EXIA movement pass

Grilled + specced + built (docs/specs/exia-movement.md). Ask: "rework how the mech moves... run and
sprint improved... good working state: moveable, run and sprint look good, pilot can get in and out,
a jump, stuff like that."

- Two gaits, one family, both built in code with solved legs: **run 9 m/s** (1.2 s cycle, upright
  jog) replaces the old 7 m/s exported walk; **sprint 14 m/s** keeps the 2026-10-13 numbers.
  `scripts/mech_sprint.gd` -> `scripts/mech_gait.gd` (generic pose-spec solver + `Gait`); the knee now
  bends in the standing knee's plane so a standing spec gives back `MECH_standing` exactly.
- New `scripts/mech_moves.gd`: stand idle (breathing), turn step, stop L/R (lead foot locked through a
  0.4 s brake, settle dip), jump crouch / air / land.
- `scripts/mech.gd`: a locomotion state (`Loco`: STAND, TURN, RUN, STOP, CROUCH, AIR, LAND) with a
  pure `next_loco()`; step-turn on the spot pivoting about the planted foot; Space = heavy jump (3 m,
  gravity x1.6, 20% air steering, coyote 0.12 s); landings scale camera dip/shake with the fall,
  heavy ones bleed speed; run footfalls get 40% of the sprint's dip and smaller dust; crouch camera
  drop and a push-off FOV kick.
- Exit: only on the floor at or below run speed; otherwise pending (`EXIT...`), F again cancels;
  `exit_spot()` tries behind, left, right, front for a clear spot with floor under it.
- `MECH_walk` / `MECH_walk_start` retired (still imported). `clip_for` / `ramp_rate` / `brake_rate`
  gone; `parked_clip`, `loco_clip`, `gait_rate`, `release_rate` replace them.
- Tests: `test_mech_sprint.gd` -> `test_mech_gait.gd` (both gaits), new `test_mech_moves.gd`,
  `test_mech.gd` walk rows replaced. Probes: `_probe_mech_moves.gd` (sheets to
  `screenshots/mech-moves/`), `_probe_mech_drive.gd` (headless physics drive).
- Suite: 1339 tests; only the known test_ichi_parked_ship failures. Boot clean.
- Not yet played.
