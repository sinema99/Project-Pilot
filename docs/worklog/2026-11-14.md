## hub2 load time (disk mesh cache)

Cause: ~1,300 Hub2Prop + 400 Hub2PipeRun + cargo containers built their meshes in code in `_ready`
every start (frame 0 = ~28 s; Dressing removed = ~4 s). Fix: `PropMeshCache`
(`scripts/props/prop_mesh_cache.gd`) saves each distinct mesh to `assets/hub2_props/*.res` on the first
game run from the editor and loads it after; builder-script md5s in `_version.txt` wipe it when the
code changes. Frame 0 now ~7 s (3.8 s is the rest of the scene, ~3 s is dressing node count).
Next if still too slow: merge Dressing into a few meshes + few collision shapes (option b).

Part 2: dressing moved to `hub2_dressing_src.tscn`, baked to `hub2_dressing.scn` (merged chunks +
multimeshes + grouped colliders). hub2.tscn 1.1 MB -> 4.6 KB; frame 0 ~7 s -> ~4.9 s. The rewire script
broke LampPools' `dressing` path (fixed back to ../Dressing). Spec: docs/specs/hub2-load-time.md.
